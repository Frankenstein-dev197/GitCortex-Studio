# Resources — GitCortex Studio

Ce dossier contient les assets de marque GitCortex Studio.

## Logos (`logos/`)

- `gitcortex-studio.svg` — logo principal (vectoriel, 512px de base).

## Icônes (`icons/`)

- `gitcortex-icon.svg` — icône d'application (vectorielle, 256px de base).

> Les formats raster (`.png`, `.ico`, `.icns`) et les manifestes de plateforme
> (Linux `.desktop`, Windows, macOS `Info.plist`) seront dérivés de ces SVG
> et placés selon la structure attendue par le build VS Code (`resources/`).

## Thèmes (`themes/`)

Réservé aux thèmes de couleur GitCortex (future `gitcortex-theme`).
