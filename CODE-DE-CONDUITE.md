# Code de conduite de GitCortex Studio

## Notre engagement

Nous nous engageons à offrir un environnement ouvert et bienveillant pour tous les contributeurs, quelles que soient leur identité, leur expérience ou leur niveau. Un comportement professionnel et respectueux est attendu en toutes circonstances.

## Normes attendues

- Faire preuve d'empathie et de respect.
- Accepter les retours constructifs.
- Se concentrer sur ce qui est le mieux pour la communauté.
- S'excuser sincèrement en cas d'erreur et apprendre de l'expérience.

## Comportements inacceptables

- Harcèlement, propos discriminatoires ou blessants.
- Trolling, insultes ou commentaires politiques non pertinents.
- Publication d'informations privées sans consentement.
- Tout autre conduite professionnellement inappropriée.

## Portée

Ce code s'applique dans tous les espaces du projet (issues, PRs, discussions, etc.).

## Application

Les cas de manquement peuvent être signalés via `SECURITE.md` ou en ouvrant une issue privée. Les mainteneurs se réservent le droit de modérer la participation en cas de comportement inapproprié.

 Inspiré des codes de conduite courants de la communauté open source.
